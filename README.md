# PaperFlow

Personal fork of [arXiv-Pulse](https://github.com/kYangLi/ArXiv-Pulse) (github.com/kYangLi/ArXiv-Pulse), customized for my own daily use. No maintenance or support is provided; issues/PRs are not accepted on this fork.

## Customizations

- Added journal sources: IEEE TGRS and Science (via Crossref metadata + Semantic Scholar abstracts)
- Sync and display can be filtered by source (arXiv / TGRS / Science)
- UI rebranded to "PaperFlow"
- Default recent-papers window: 1 day
